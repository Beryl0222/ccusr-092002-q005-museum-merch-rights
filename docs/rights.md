# 权利与履约边界

作品入藏不代表美术馆同时取得复制、改编和商业销售所需的全部权利。系统把许可边界建模为
六个可判定的维度，并要求每条许可关联证据：

- **用途**：`exhibition-promotion`（宣传图、展讯、直播预热）、`product-reproduction`
  （商品复制）、`product-adaptation`（二创改编）。用途之间互相独立：宣传获准不等于
  商品获准；改编产品必须同时具备复制与改编两项用途。
- **渠道**：`museum-store`（馆内商店）、`official-online-store`、`livestream`（直播）、
  `popup`（外部快闪）等；`*` 表示不限。
- **地域**：如 `CN`、`US`；`*` 表示不限。
- **期限**：`valid_from` / `valid_until`，按日比较；到期巡查会把过期许可置为 `expired`。
- **状态与证据**：许可必须有合同、邮件或书面同意等证据文件才生效；可登记撤回通知，
  撤回后置为 `revoked` 并保留全部历史。
- **转授权与版税**：`sublicensable` 标记可否转授权；版税按比例（`royalty_rate`）或
  单件费用（`royalty_unit_fee`）约定。

## 门禁

产品从设计到销售经历内容审核、打样、采购、生产、检验和上架。

- **采购门禁**：采购单创建与锁定产能两个时点都校验——所需用途许可全部有效、有证据、
  内容审核通过；可附带目标渠道/地域列表预检，防止为未获授权的渠道提前备货。
- **上架门禁**：每个渠道/地域的 listing 单独过门禁。
- **成交门禁**：下单时对版本实时重评权利与审核，因此即使撤回/到期后来不及人工下架，
  线上也无法继续成交。

## 事件处置

许可撤回、许可到期、特展改期、供应商延期、质检不合格统一进入 incidents 流程，
生成 applied（已执行）或 pending（待人工决策）动作，每条动作带文字解释：

- 撤回/到期 → `suspend_sale` 停售、`halt_production` 停产；已锁定的采购承诺保留
  （`committed=1`，按合同结算，不删历史单据）。
- 撤回 → 撤回日前已下单未发货部分进入 `refund_or_substitute`；已发货不追回。
- 到期 → 期内已成交订单继续履行；停产使可承诺库存（ATP）不足时才产生退款/替代。
- 改期 → `renew_license` 续签待办与按新展期开始日的预防性 `suspend_sale`。
- 延期 → `preserve_commitment`；新交期晚于许可到期时追加 `rework_or_reorder` 建议。
- 质检不合格 → 不合格品隔离不入库；ATP 转负时按订单时间顺序生成缺口的退款/替代动作。

历史产品与合同不被删除，处置过程全部可从事件和商品两侧追溯。

## 库存与版税

直播、馆内商店和快闪渠道共享实物库存。可承诺量 ATP = 在手 + 在途（未停产、未质检报废的
采购数量）− 已占用；各渠道另设预留额度。下单在同一 `BEGIN IMMEDIATE` 事务内同时校验
全局 ATP 与渠道预留，订单取消与部分发货立即释放或保留对应占用，不产生超卖或重复占用。

版税以**下单时快照的有效许可**为权利依据、以**实际净销售**为金额依据：发货时确认销售，
未发货部分的退款不冲减净销售；结算周期与逐笔明细一并留存。
