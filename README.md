# 美术馆文创授权履约系统

面向公立美术馆特展文创的后端系统：把每件作品在**复制、改编、宣传、地域、渠道、期限**
上的许可边界与证据关联起来，贯穿策展、授权、打样、内容审核、采购、生产、质检、
多渠道销售与版税结算。

## 解决的问题

- **权利边界可执行**：宣传许可与商品复制许可互不可替代；用途/渠道/地域/期限/凭证
  五者齐备，产品版本才能采购或上架，闸门结果逐市场留快照。
- **异常可解释、承诺可保留**：特展改期、授权撤回/到期、供应商延期、质检不合格
  统一生成「事件→工单→动作」，自动停售/停产/退款/隔离，续展/替代/重订挂起人工裁决；
  已确认的采购合同与已发生的销售不删除。
- **共享库存不超卖**：直播、馆内商店、外部快闪共享同一批次实物池，各有预留额度；
  下单、取消、部分发货全程事务化，直播秒空不能重复占用线下额度。
- **版税按实际净销售**：发货时按当时有效授权与作品份额计提，退款冲回，按权利人区间结算。
- **风险可视、来源可溯**：临展结束前风险、库存敞口、待续权利看板；任一商品版本
  可回溯作品来源、授权证据、审批、闸门、采购批次质检、订单发货退款与版税全记录。

## 快速开始

```bash
# 启动（DATABASE_SEED=1 写入一个完整演示场景）
PYTHONPATH=src DATABASE_PATH=museum.db DATABASE_SEED=1 PORT=8080 \
  python -m museum_merch.main

curl localhost:8080/health
curl "localhost:8080/api/exhibitions/ex-ink-2026/risk?on=2026-09-20"
curl "localhost:8080/api/versions/ver-scarf-v1/trace"
```

## 运行测试

```bash
PYTHONPATH=src python -m unittest discover -s tests
```

38 个用例覆盖：用途/渠道/地域/期限/凭证闸门、采购承诺、质检隔离、
渠道额度与并发超卖、部分发货取消、撤回/到期/改期/延期处置、替代裁决、
版税计提冲回结算、续展恢复与 HTTP API 端到端。
